# 🎂 Happy Birthday Jonida!

Eine vollständig animierte Geburtstagsseite zum 20. Geburtstag von Jonida.

## Öffnen

`index.html` einfach im Browser öffnen – keine Installation, keine Abhängigkeiten.

## Features

- Animierter Farbverlauf-Hintergrund mit leuchtenden Blobs und funkelnden Sternen
- Buchstabe-für-Buchstabe Namens-Animation + schimmernder Gradient-Titel
- 3D-Flip-Animation der Zahl **20**
- Aufsteigende Ballons in sechs Farben
- Konfetti- und Feuerwerk-Engine auf Canvas (Klick irgendwo = Feuerwerk)
- Interaktive Torte: antippen und die Kerzen auspusten (mit Rauch-Effekt)
- "Happy Birthday"-Melodie über die Web Audio API – ganz ohne Sounddateien
- Typewriter-Textschleife, Scroll-Reveal-Animationen und hochzählende Zahlen
- Responsive für Handy und Desktop, respektiert `prefers-reduced-motion`
